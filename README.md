# Peramalan-Harga-Beras-di-Indonesia

Deskripsi Proyek: Proyek ini membahas peramalan harga beras di Indonesia menggunakan metode Fuzzy Time Series Cheng yang dioptimasi dengan Particle Swarm Optimization (PSO) dan Artificial Bee Colony (ABC). Penelitian dilakukan untuk membandingkan kinerja kedua algoritma optimasi dalam meningkatkan akurasi hasil peramalan.

Metode: Fuzzy Time Series Cheng, Particle Swarm Optimization (PSO), Artificial Bee Colony (ABC).

Tools: Python, Google Colab.

Konteks Proyek: Penelitian tugas akhir (skripsi) dan publikasi ilmiah.
